# **App Name**: PermitFlow

## Core Features:

- User Registration and Management: User registration form with username, email, mobile, password, and confirm password. Admin manages user roles (Admin, Supervisor, Site Engineer) and approves registration requests.
- Project and Site Management: Admin can add sites and users and assign projects to users.  Sites selectable in PtW request form.
- Permit to Work (PtW) Request: Site Engineer can raise a PtW request by selecting a site and PtW type, providing a description of work, attaching a video of the work, and a vlog.
- PtW Request Review and Approval: Supervisor can review submitted PtW requests. Admin can accept or reject requests, providing feedback for corrections.  Rejected requests are returned to the Site Engineer.
- PtW Summary Reports: Admin and Supervisor users can generate summary reports of PtW, filtering by site.
- User Dashboard: Left sidebar navigation with collapsible options: Projects, PtW (Raise PtW, List of my PtW), Settings (User Management). Role-based access control.
- Login and Logout: Secure user authentication system with login and logout functionality.

## Style Guidelines:

- Primary color: Deep blue (#1E3A8A), for a professional and trustworthy feel, reflecting the serious nature of safety management.
- Background color: Light gray (#F9FAFB), providing a clean and modern admin panel look.
- Accent color: Teal (#38B2AC), used for interactive elements and highlights to draw attention to key actions.
- Headline font: 'Space Grotesk', sans-serif. Body font: 'Inter', sans-serif for a modern and readable admin panel experience.
- Use a set of consistent and clear icons to represent different actions and modules within the application.  Icons should be easily understandable.
- Admin panel layout with a left sidebar for navigation. Collapsible sidebar functionality for improved screen space.  Clear separation of content areas.
- Subtle transitions and animations for page loading and content updates to enhance the user experience without being distracting.
